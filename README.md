# Project Task Manager (FS07P1A)

A robust, backend-driven To-Do List application built with Node.js, Express, and MongoDB. This project strictly adheres to the Model-View-Controller (MVC) architectural pattern and utilizes Server-Side Rendering (SSR) via EJS.

## ✨ Features
*   **Strict MVC Architecture:** Clean separation of business logic, data modeling, and UI.
*   **Dynamic Category Filtering:** Instantly sort tasks by 'Work', 'Study', or 'Personal'.
*   **Intelligent Deadline Alerts:** Algorithmic date-checking automatically flags overdue tasks in **red** and tasks due today in **orange**.
*   **Cloud Ready:** Configured for deployment on AWS EC2.

## 💻 Local Installation & Setup

1. **Install dependencies:** `npm install`
2. **Start the database:** Ensure MongoDB is running locally on port `27017`.
3. **Run the server:** `npm start` (Runs at `http://localhost:3000`)
